# 本地漫画阅读器

一个完全在浏览器本地运行的漫画阅读器。图片和压缩包不会上传到服务器。

## 使用方式

直接打开 `index.html`，然后选择以下任一来源：

- 包含图片的文件夹；
- `.zip` 或 `.cbz` 漫画压缩包；
- 把图片或压缩包拖入阅读区域。

支持的图片格式：JPEG、PNG、GIF、WebP、BMP、AVIF。

## 阅读操作

- 单击阅读区域左右半边翻页；
- `←` / `→`、`PageUp` / `PageDown` 翻页；
- `Home` / `End` 跳到开头或结尾；
- 空格开始或停止自动翻页；
- `F` 进入或退出全屏；
- 支持单页/双页和从左到右/从右到左阅读；
- 手机端可以左右滑动翻页。

阅读模式、方向、自动翻页间隔和最近 20 本漫画的进度保存在浏览器本地。

## 压缩包说明

ZIP/CBZ 解压由项目内置的 [fflate](https://github.com/101arrowz/fflate) 完成，因此无需联网。暂不支持 RAR、7z、加密压缩包，以及 ZIP 中使用非 Store/Deflate 算法压缩的图片。

为避免异常压缩包耗尽浏览器内存，单个压缩包、解压后的图片总量和图片数量分别设有安全上限。

第三方许可证见 `vendor/fflate.LICENSE.txt`。
